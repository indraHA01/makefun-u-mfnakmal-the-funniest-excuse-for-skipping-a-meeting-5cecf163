# The Funniest Excuse for Skipping a Meeting

One razor-sharp line that gets you out of a pointless meeting — an entry for make.fun's "The Funniest Excuse for Skipping a Meeting" bounty ($10). The program is fully deterministic: no network, no randomness, it writes the same 88 characters every run.

## The entry

> Can't join — I'm stuck in a meeting about this meeting, and it's somehow running over.

The angle: the excuse IS a meeting. Not bad wifi, not a cat, not a dentist — the sender is already trapped in a meeting about this very meeting, and that meeting is running over. Every office worker recognises the loop instantly: meetings spawning meetings, none of them ever ending on time. The punch lands in the last three words, because a meeting about a meeting should take thirty seconds, and yet here we are.

## Run

```sh
node main.ts        # writes /output/entry.txt
```
